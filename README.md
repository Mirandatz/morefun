# MOREFUN

## Creating container

Run `make dev_env` to create a dev container, see `Makefile` to find the container tag or name.

## Testing

Run `make run_tests` to run the test suit in parallel or `make run_tests_sequential` to run the test suit sequentially.

## Experimeting

Minimal dependencies: Python 3.10 and `typer` (a Python library). Run `./scripts/experiments/run_experiment.py --help` to get instructions on how to run experiments
